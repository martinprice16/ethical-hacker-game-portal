## FAQ

**How are updates made?**  
Change the HTML, then push or upload the revised files to your host.

**Which host should I use?**  
The profile targets GitHub Pages, though other static hosts are fine as well.

**Is the layout fixed?**  
No. Because everything is HTML, you can reshape structure directly in the source.

**The page fails to load—what next?**  
Inspect the browser console, verify the entry file path, and confirm the published folder matches your host settings.
